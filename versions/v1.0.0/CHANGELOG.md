# v1.0.0 — Initial Release

Released: June 16, 2026

## Features
- Recipe storage, search, and organization with images and collections
- Chef Terry — AI cooking assistant with personality, recipe generation, and mid-cook help
- Terry Vision — scan fridge/pantry with camera, get recipe suggestions
- Weekly meal planner with AI-powered suggestions
- Smart shopping list with ingredient consolidation
- Cook Mode — step-by-step with large text, auto-detected timers, keep-awake
- Push notifications — morning meal prep reminders and perishable ingredient alerts
- Unit conversion, nutrition estimation, dietary profile auditing
- 7 themes + Material You support
- Offline-first with server sync

## Stack
- Server: Node.js + Express + SQLite (Docker)
- Mobile: Expo SDK 56 (React Native)
- AI: any OpenAI-compatible provider (DeepSeek, Groq, OpenAI, Ollama, etc.)

## Distribution
- APK download via GitHub Releases
- Docker container for self-hosting
- Website: cegin.kitchen
