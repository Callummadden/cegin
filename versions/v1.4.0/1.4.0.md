# v1.4.0 — Nutrition Accuracy Overhaul

**Date:** 2026-07-13  
**Focus:** Honest, per-serving nutrition for *user* recipes — structure once, USDA math, store on recipe.

---

## Goal

Make **NUTRITION PER SERVING** as accurate and honest as possible without becoming a commercial food-data company. Prefer:

1. Clean structured ingredients  
2. Deterministic USDA linking  
3. Explicit skip of no-amount toppings  
4. Persist results so we do not re-roll AI every open  

See also: [NUTRITION_SOLUTIONS.md](./NUTRITION_SOLUTIONS.md) — longer discussion of the problem and future options.

---

## Architecture (final 1.4 model)

```
Recipe ingredients (free text)
        │
        ▼
  AI structure pass (once per change)
  → qty, unit, food, include yes/no
        │
        ▼
  USDA FoodData lookup + grams
        │
        ▼
  Optional AI only for measured unmatched lines
        │
        ▼
  Batch total ÷ recipe.servings
        │
        ▼
  Save nutrition_data on recipe
  (instant reload until ingredients change)
```

**Per serving** = full batch macros ÷ **recipe servings field** (not the display SERVINGS scaler).

## What’s in 1.4.0

### Structured estimate path
- **Primary:** AI normalizes cookbook English → `linkStructuredIngredients()` → USDA  
- **Fallback:** legacy free-text USDA heuristic + measured-line AI gap-fill  
- **Last resort:** whole-recipe AI batch estimate  
- Loading copy: `Structuring ingredients → USDA…`  
- Footer: `AI structure + USDA` or `stored on recipe`

### Persist on recipe (`nutrition_data`)
- Server: `recipes.nutrition_data` TEXT (JSON), migration via `ALTER TABLE`  
- Mobile `localDb` + mirror sync  
- Payload: `ingredients_fp`, `servings`, `lines[]`, method, source, `computed_at`  
- **ESTIMATE** reuses store when fingerprint matches (offline recompute)  
- **↻** forces full restructure and overwrite  
- Edit recipe clears `nutrition_data` when ingredients or servings change  

### Ingredient breakdown UI
- Collapsed by default (`▸ INGREDIENT BREAKDOWN`)  
- Status: `MATCHED`, `AI`, `USER`, `SKIPPED` (ignored), `UNMATCHED`  
- **counted as:** cleaned line when different from raw  
- Liquids show **ml** (not always g); 1 ml stock ≈ 1 g for macros  
- LINK FOOD / CHANGE / GRAMS / IGNORE / RESTORE  

### Skipped-ingredients popup
- After estimate, if items were left out of the total:  
  - Lists each skipped line + reason  
  - Explains need for amounts (`15ml soy sauce`, `5g chili oil`)  
  - **Edit ingredients** → Edit recipe; **Got it** dismisses  

### Servings discipline
- Estimate requires `recipe.servings > 0`  
- Label: `Full batch ÷ N recipe servings · batch ~X kcal`  
- Display SERVINGS +/− scales ingredients only — does **not** change per-serving macros  
- Servings-suspect warning when mass-per-serving looks absurd  
- Servings-only change recomputes from stored lines (no AI)  

### Cookbook / parser hardening
- Alternatives: `chicken or beef stock` → first option (+ shared tail e.g. `chicken stock`)  
- Strip page notes, long asides, `(see… page N)`  
- Dual units: `170g ¾ cup` → prefer **grams**  
- Volume: `6 cups (1.5 liters)` → **1500ml**  
- Headers skipped: `Options for topping:`  
- Unmeasured condiments **not** AI-invented (soy, chili oil, etc.)  
- Green onion / scallion defaults (~15g), not whole onion  
- Rice: bias white/short-grain; reject noodles, crackers, snacks, black rice unless named  
- Chili oil → canola/vegetable oil mapping (not “oil, oat”)  

### Expo / app stability
- Removed `React.lazy` for screens (HMR `window.location.reload` crash on native)  

### AI prompts
- Server `NUTRITION_PROMPT` + local AI: sum batch, then divide by servings  
- Structure prompt: include/exclude, first alternative, no ghost pours

## How to use (trustworthy numbers)

1. Set **recipe servings** = how many people the written list feeds  
2. Prefer amounts in the list: `400g`, `1500ml`, `2 tbsp`  
3. Tap **ESTIMATE** once (structures + saves on recipe)  
4. Read the popup if items were skipped — add amounts if you want them counted  
5. Open breakdown only if you want to audit/fix matches  
6. **↻** only when you want a full restructure  

---

## Known limits (by design)

- Bundled USDA subset: **~5 macros** (cal, protein, carbs, fat, fiber)  
- Optional toppings without amounts stay **out** of the total (honest, not inflated)  
- AI structure quality depends on provider/model  
- Wrong recipe servings still wrong-scales the whole plate
