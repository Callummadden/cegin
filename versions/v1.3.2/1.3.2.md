# v1.3.2 — Bug Fix Release

## Full server + app bug run fixes

### Server (docker, health, middleware, versions)
- Fixed healthcheck using `localhost` (BusyBox wget prefers IPv6 `::1` but Node binds to 0.0.0.0). Now uses `127.0.0.1` in both `docker-compose.yml` and `Dockerfile`.
- Bumped `server/package.json` to 1.3.1 (was stuck at 1.2.0) so `serverVersion` matches `LATEST_SERVER_VERSION` — eliminates false "server outdated" warnings.
- Refactored body-parser and auth middleware with `getRoutePath()` helper using `originalUrl` for consistent path handling regardless of mount point.
- Improved `npm test` to actual smoke tests (syntax + core module loads).
- Reduced noisy WS logs in production with `debugLog` helper.
- Updated `LATEST_CLIENT_VERSION` for new release.
- Rebuilt and pushed updated image to Docker Hub (`callum2254/cegin:latest` + `1.3.1`).

### Mobile (deps, config, versions)
- Cleaned and fixed Expo dependency issues (missing `expo-font` peer, duplicates).
- Fixed app.json schema error for `splash` by moving config into `expo-splash-screen` plugin.
- Bumped version to 1.3.2 (versionCode 17).
- `expo-doctor` now passes 20/21 checks.

### Docs and release
- Updated version references in docs, badges, and download links.
- New `versions/v1.3.2/1.3.2.md`.
