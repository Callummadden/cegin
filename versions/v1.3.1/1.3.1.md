# v1.3.1 — Bug Fix Release

## server/index.js
- **#1** Nutrition endpoint now returns result — added missing `res.json(nutrition)` in success path
- **#2** `/api/auth/me` returns 401 instead of crashing 500 when no token provided
- **#7** Meal planner endpoint accepts client-provided `goal` and `recipes` params, passes goal through to AI prompt
- **#9** `/api/image-proxy` now validates URL scheme, resolves DNS, and blocks private/reserved IPs (SSRF protection)
- **#11** Health endpoint versions bumped from 1.2.0 to 1.3.0

## server/ai.js
- **#5** `callVisionModel` OpenAI path now returns JSON string (matching Gemini) so callers parse uniformly — fixes empty fridge scan results
- **#7** `suggestMealPlan` accepts `goal` parameter and includes it in the planning prompt (e.g. high-protein, balanced, low-carb)

## server/db.js
- **#4** `getSubscribedUsers` uses LEFT JOIN on users — user_id=0 subscribers (typical self-hosted setup) now included in cron push notifications
- **#10** Collections uniqueness scoped per user — replaced global `UNIQUE(name)` with `UNIQUE(user_id, name)` index

## mobile/src/screens/AssistantScreen.js
- **#3** Terry's `add_meal` action converts day offset to YYYY-MM-DD date string before calling `setMeal` — meal plan actions now land on the correct day

## mobile/src/screens/RecipeDetailScreen.js
- **#6** AI nutrition fallback spreads `r` directly instead of `r.nutrition` — fixes undefined/zeros when USDA lookup fails

## mobile/src/localAi.js
- **#8** `generateShoppingList` accepts optional recipes array with full ingredient lists — local model can now consolidate ingredients correctly

## mobile/src/usdaNutrition.js
- **#12** Staleness check reads `meta.db_version` table and re-copies DB when bundled `DB_VERSION` increases

## mobile/src/api.js
- **#13** `remapTempId()` replaces offline temp IDs in recipe cache, meal plan, and favorites after server sync
- **#19** Request function attaches `Authorization: Bearer` header when token exists in AsyncStorage (optional — app still works in open mode)
