# Changelog

## 1.3.0 — 2026-06-21

### Local USDA Nutrition Engine
- Bundled SQLite database with 14,046 foods (SR Legacy + Foundation Foods) — fully offline at 2.7MB
- 6-strategy search pipeline: exact match → starts-with → UK/AU/CA alias → FTS5 full-text → de-pluralization → last-word fallback
- UK-to-US translation dictionary (80+ mappings): lamb mince→ground lamb, courgette→zucchini, plain flour→all-purpose flour, etc.
- Per-food unit conversions with exact USDA gram weights (e.g. 1 cup oats = 81g)
- Custom unit conversions for produce ("1 medium banana"→120g), colloquial ("1 handful spinach"→30g), and tins/cans
- Metric liquid volumes (ml/litre) handled as 1:1 gram equivalents
- Atwater validation — calories recalculated from macros with correct net-carb formula

### Instant Allergen Detection
- Local allergen flags for 7,119 foods — gluten, dairy, nuts, soy, eggs, shellfish detected instantly (no API needed)
- Colored badges displayed at top of recipe on load
- Batched queries in groups of 20 to avoid SQLite parameter limits

### Terry's Dietary Suggestions
- "Apply Terry's Suggestions" button collects audit substitutions and sends to AI to modify the recipe
- Substitution picker modal with radio buttons when Terry suggests multiple options
- Custom substitution entry — users can type their own swaps
- Quantified substitutions with exact quantities ("swap 100g butter for 100g ghee")
- Change highlighting — Terry's additions shown as red text with red banner
- Edit tracking clears highlighting once user starts editing
- Original recipe image preserved through the substitution flow
- Profile-only audits — Terry only audits for people in Health & Diet profiles

### Pre-processing Pipeline
- Compound line splitter — "For the sauce: 100g butter, 150g dark sugar" → 3 separate items
- Narrative prefix stripper — removes "For the filling:", "Toppings:", etc.
- Bracket weight extractor — "1 tin coconut milk (400ml)" → "400ml coconut milk"
- Prep-instruction stripper — "500g chicken thighs, diced" → "500g chicken thighs"
- Count-based produce weights — "2 carrots"→120g, "1 clove garlic"→5g

### Dietary Audit Intelligence
- Audit only runs for people in Health & Diet profiles — never invents names
- Auto-collapses to compact green bar when all profiles are safe
- Substitution prompt includes explicit quantity instructions

### Fixes
- Fixed crash on app reset — `clearFavorites` was missing from favorites module

- Fixed activity cache not clearing when diet profiles are cleared
